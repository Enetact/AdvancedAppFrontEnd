## What is this app?

- React app bundled with **Vite**
- Uses **React Router DOM** with **HashRouter** for compatibility with static hosting
- Styling via **Bootstrap 5** (loaded from CDN)
- PWA-ready with:
  - `manifest.json`
  - `public/service-worker.js` with versioned caches, precache, and runtime strategies

For an overview of recent work, see the [CHANGELOG](../../CHANGELOG.md).
